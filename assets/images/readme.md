# Folder Aset Gambar

Folder ini dapat digunakan untuk menyimpan aset gambar statis yang mungkin diperlukan oleh aplikasi.

## Untuk Admin Sekolah:

Jika Anda perlu mengganti foto guru atau siswa secara manual melalui kode, Anda dapat menempatkan file gambar di sini sebagai referensi.

**Sangat disarankan** untuk menamai file gambar sesuai dengan **Kode Unik Foto** yang ditampilkan di aplikasi untuk menghindari kesalahan.

- **Contoh Nama File Foto Guru:** `G-1720123456789.png`
- **Contoh Nama File Foto Siswa:** `S-1001.jpg`

Setelah menempatkan file di sini, Anda perlu memperbarui path gambar di dalam kode sumber aplikasi secara manual. Metode utama untuk mengganti foto tetap melalui antarmuka unggah di dalam aplikasi, karena data gambar disimpan langsung di browser.
